Vermissten-Bericht

So funktioniert's:
  • Klicken Sie auf die Karte, um die Position zu markieren, wo Ihr Tier zuletzt gesehen wurde
  • Nutzen Sie den Button "Aktuellen Standort verwenden", falls das Tier an Ihrem aktuellen Standort verschwunden ist
  • Sie können den roten Marker verschieben, um die Position anzupassen
  • Zoomen Sie mit dem Mausrad oder den +/- Buttons für eine genauere Position
Ausgewählte Position:
Latitude: Noch nicht ausgewählt
Longitude: Noch nicht ausgewählt
Bitte wählen Sie eine Position auf der Karte aus!
Beschreibe die Situation, in der das Tier verschwunden ist
Ein Finderlohn kann die Motivation erhöhen
Wichtig:
Durch das Absenden wird dein Tier als vermisst markiert. Alle Nutzer können dann deine Kontaktdaten sehen, falls sie dein Tier finden.
Abbrechen

Was passiert nach der Meldung?

  • Dein Tier erscheint in der öffentlichen Liste vermisster Tiere
  • Finder können Fotos hochladen, die automatisch mit deinem Tier abgeglichen werden
  • Bei einer Übereinstimmung wirst du sofort benachrichtigt
  • Deine Kontaktdaten werden für potenzielle Finder sichtbar
