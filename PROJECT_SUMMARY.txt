🚀 SCHNELLSTART (5 Befehle)

1. Datenbank initialisieren:
   mysql -u root < database/schema.sql

2. PHP Backend starten:
   cd backend && php -S localhost:8001

3. Python AI Service starten (neues Terminal):
   cd ai-service && pip install -r requirements.txt && python main.py

4. Frontend öffnen:
   http://localhost:8001/frontend/pages/index.html

5. Test durchführen:
   • Registriere einen Benutzer
   • Gehe zu "Tier gefunden?" 
   • Lade ein Katzenbild hoch per Drag & Drop
   • Sieh die KI-Ergebnisse 🎉

   Detaillierter Guide: QUICKSTART.md
